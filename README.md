# Quillfeather Studio Site

Static public website for Quillfeather Studio, deployed through Vercel.

## Public URLs

- Website: https://www.quillfeatherstudio.app/
- Privacy policy: https://www.quillfeatherstudio.app/privacy.html
- Terms: https://www.quillfeatherstudio.app/terms.html

## Structure

- `index.html` — brand homepage and marketplace links
- `privacy.html` — privacy policy for the website and private Etsy/Pinterest tools
- `terms.html` — website and digital-product terms
- `style.css` — responsive light/dark styling

The site is static and contains no secrets, forms, analytics, cookies, or client-side scripts.
